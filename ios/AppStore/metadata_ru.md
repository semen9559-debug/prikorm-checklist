## Описание (4000 символов)
Мама рядом — цифровой помощник для родителей в первый год жизни малыша. 
Всё необходимое в одном приложении: без рекламы, без навязчивых уведомлений.

**Трекер прикорма 5,5–12 месяцев**
Что и когда вводить малышу — по шагам, с советом на каждый продукт. 
Отмечайте реакцию, добавляйте свои продукты, следите за прогрессом.

**Дневник дня**
Записывайте кормления, сон, подгузники, прогулки и другие события. 
Таймер сна и кормления прямо в приложении. Наглядная сводка дня. 
Отчёт для педиатра — экспортируйте данные в один клик.

**Развитие по месяцам**
Навыки и умения по месяцам — что должен уметь малыш. 
Личный календарь недель: отслеживайте периоды развития. 
Режим сна по возрасту: нормы дневного и ночного сна.

**Сумка в роддом**
Полный список необходимого для мамы, папы и малыша. 
Отмечайте собранные вещи, добавляйте свои.

**Документы и выплаты**
Что оформить после рождения и какие выплаты получить. 
Информация по национальному законодательству РФ 2026.

**Прививки**
Национальный календарь прививок. Отмечайте выполненные вакцинации.

**Беременность по триместрам**
Скрининги, анализы и подготовка к родам — вовремя и по порядку.

**Синхронизация семьи**
Делитесь данными с партнёром — оба видят одни и те же записи в режиме реального времени. 
Данные хранятся только на вашем устройстве. Семейная синхронизация — строго по желанию.

**Конфиденциальность**
Никакой рекламы. Никакой аналитики. Никаких трекеров.
Все данные хранятся локально на устройстве. 
Облачная синхронизация включается только по вашему выбору.

*Информация в приложении носит справочный характер. Сроки введения прикорма и навыки развития — ориентировочные. По всем вопросам здоровья малыша обращайтесь к педиатру.*

## Заметки для рецензента Apple
Это нативное iOS-приложение, использующее WKWebView для отображения 
локально-встроенного веб-приложения. Все функции работают без интернета 
(данные хранятся в localStorage). Для тестирования аккаунт не требуется — 
приложение полностью работает без регистрации. Функция «Семья» (опциональная) 
требует создания аккаунта, но не является обязательной для использования.

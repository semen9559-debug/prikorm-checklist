# Мама рядом — тестовая семейная синхронизация

Приложение остаётся доступным без аккаунта: данные хранятся локально. Для теста регистрации и совместного доступа подключите тестовый Supabase-проект.

1. Создайте проект Supabase и включите Email/Password authentication.
2. В **Auth → URL Configuration** добавьте `https://prikorm.dverizapeli.ru` в Site URL и Redirect URLs. Для локального теста добавьте `http://127.0.0.1:4173`.
3. Выполните целиком [`supabase/schema.sql`](supabase/schema.sql) в SQL Editor проекта.
4. Скопируйте Project URL и **publishable anon key** в [`scripts/supabase-config.js`](scripts/supabase-config.js). Не используйте service_role key.
5. Зарегистрируйте два тестовых аккаунта, войдите первым, импортируйте локальные данные и создайте приглашение в разделе «Аккаунт и семья».

Email-приглашение в тестовой версии открывает подготовленное письмо через установленный почтовый клиент. Это позволяет обкатать процесс без серверной почтовой интеграции. Для автоматической отправки в production понадобится SMTP-провайдер или Supabase Edge Function.
